## How to re-run these prompts

1. Get a free API key at https://console.groq.com/keys.
2. `cp .env.example .env` and set `LLM_API_KEY`.
3. `pip install -r requirements.txt`
4. Run one module and version, e.g. `python -m scripts.generate_tests --module login --version v4`.

The script sends the prompt file unchanged and saves the verbatim response plus a validation report under `generated/raw/`. Compare your report with the one listed below. Groq does not return byte-identical output even at temperature 0, so expect the same structure and coverage, not the same wording.

On the free tier, run modules one at a time: each run uses about 8-10k tokens and the limit is 8,000 tokens per minute. The client backs off and retries automatically.

To use a local model instead, set `LLM_BASE_URL=http://localhost:11434/v1` and `LLM_MODEL` to an Ollama model; nothing else changes.

  `/login?reason=logged_out`, which shows exactly "You have been signed out." in `login-notice`.

  link.
